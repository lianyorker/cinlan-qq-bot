# 真人化技术方案

> 目标：让机器人在 QQ 群/私聊里的行为分布接近真人——说话节奏、记忆、情绪、关系、主动性都有内部状态，而不是无状态应答机。
> 所有机制均为自研，集中在 `internal/bot`、`internal/chatprefs`、`internal/mood`、`internal/proactive`、`internal/reflect`、`internal/session`、`internal/vecstore`。cinlan-bot/core 有对应镜像。

## 分层总览

```
入站 ── batch 合并窗 ── 注意力路由 ── 安全/隔离 ── 会话装配 ── Agent
                                                              │
出站 ← 真人化出站层（拆分/标记/剥除/声纹/节k奏） ←── 生成 ←── 状态注入（mood/记忆/好感/印象/承诺/速写）
```

## 1. 可塑性记忆（chatprefs + vecstore + reflect）

**短期事实 + 长期归档 + 语义召回**，三段式：

- `chatEntry.Facts`（上限 40）+ `Archive`（上限 400）：活跃池溢出转入归档，不丢。
- fact 结构：`{Text, CreatedAt, LastSeenAt, Weight}`；召回打分 = CJK bigram + 概念簇命中 + 远程稠密向量（`vecstore` 双引擎：本地 256 维 L2 归一化特征向量 / OpenAI 兼容 embeddings + SHA-256 磁盘缓存，0.7/0.3 融合）。
- 召回即刷 `LastSeenAt` 热度（+0.25 上限 3，打分×权重）；容量裁剪丢最旧未召回。
- `memoryWorthy` 写入质量门：小于 4 rune + filler 黑名单拒写，「在吗」这类垃圾不进记忆。
- `reflect` 每 30 分钟 housekeeping：
  - facts >20 → LLM 浓缩合并（**没缩小就保留原样**，防模型摆烂）；
  - impressions >40 → 最旧一半浓缩成 ≤3 条「群友速写」fact；
  - journal：绑定群 24h 内活跃且无今日日记 → persona 声线写 1-2 行 `日记·MM.DD` fact，走正常召回。
- 承诺跟踪：`notePromise` → `承诺·` fact → `PromiseFacts` 注入 prompt + proactive，>24h 附日期锚。
- 纠错观察：`[纠错]` 写会话；语气守卫 `ToneBans` ≤20 + `applyToneGuard` 前置预防 + 出站剥除兜底。
- 遗忘是特性：`ReplaceFact`/`forget` 需子串包含或 >50% bigram 重叠才删，防误删。

## 2. 会话（session）

- 原始 history 24h TTL；过期后 **Summary + Memory 语义层保留 365 天**（`SESSION_SEMANTIC_TTL`）——「忘了原话但记得聊过啥」。
- 每条 history 带 `[MM-DD HH:mm]` 戳，assistant 轮次亦然——她对自己的"上次说过"有时间感。
- `foldSpam`：连续 >5 条 user run 折叠为「首2 + [中间的 N 条已省略] + 尾2」，防刷屏占上下文。
- `batch.go` 合并窗：群/私聊默认 1500ms，`tailLooksIncomplete` 尾部悬挂标点或接续词 → +2s 续等；完整句不等满。私聊连发同 batchKey 合一个 run（防双烧生图额度）。
- `AddExchange`/`AddObservation` 带 dedupe，self-action 统一写 `[动作]` 观察（生图/语音/定时/poke/欢迎语），被问「你刚才干了啥」能从自己历史答。

## 3. 情绪（mood）

- 每聊 `moodScore` ±100：被@夸 +6 / 被骂 -8 / 中性 +3，6 分/小时自然衰减。
- `mood.Hint` 分档注入；`mood.Scene(now, score)` 给「你在干嘛」一个时钟锚定的生活状态，跨轮不矛盾。
- `mood.Circadian`：19-23 点 proactive ×1.2；`Asleep` 睡眠窗回复变短变迷糊。
- mood→action：≤-60 自动装死 30min；≤-30 不主动开口；≥30 开口率 ×1.5。
- **burst steering**：mood≥70 时 35% 概率注入「兴致高可连发」；0-30 时 50% 注入「敷衍回一句」——泡数由心情驱动而非定值。
- **softSplitReply 心情漂移**（10-26 新）：机器拆分概率 = 长度基础带（30%/55%/80%）+ moodAdj（±0.33），钳 5%-95%。开心多说几泡、丧着回一句，旁人算不出规律。

## 4. 好感度（affinity）

- key = `platform:selfID:userID`，分数阈值 陌生0/认识5/熟悉20/亲近60/亲密150，展示钳 0-100。
- `affinity_prompts` 按人格分档注入；`/亲密度` 命令可查；私聊和 allowed_users 恒满级。
- `maybeLike`：私聊亲密度 ≥20 时 send_like 小动作。
- **分数不外报**：prompt 里只给内心校准，被问用等级口语答，精确数字引导 /亲密度。
- 回答正交于「记住谁」——好感是关系深度，UserCard 是公开画像。

## 5. 粘性上下文（attention + 疲劳 + 回声抑制）

- `ai_decide` 路由：attention 分类器判 respond/observe/ignore/unsafe（unsafe 硬拦）；阈值 cinlan 群 0.62、zkmall 群 0.68；direct @ / 白名单绕过；on_error 兜底 mention_only。
- `routing_scope`：persona 的 description + include/exclude_topics + 正反例，决定"这话该不该接"。
- mention-fatigue：15 分钟窗被连@ 3 次 → 冷处理（真人被刷屏会烦）。
- `filterSelfEcho` + `trimRepeatedSpan`：与最近 8 条自己发言的最长公共子串 ≥5 rune 就剥——不自复读。
- wrap-up hint：history ≥12 且 mood <40 → 提示「可以像真人一样主动收尾」。
- `pendingFollowUp`：被追问过的会话保持应答倾向，聊断不断线。

## 6. 真人动作与标记（reply_plan + actions）

出站标记全在 `stageRespond` 解析，不进工具白名单：

| 标记 | 行为 |
|---|---|
| `[[NEXT]]` | 主动分泡（≤ CHUNKS，现网 3） |
| `[[MEME:x]]` / `[[IMG:key]]` / `[[SELFIE:x]]` | 梗图池/记住的图/人格贴纸包 |
| `[[REACT:x]]` | set_msg_emoji_like 贴表情 |
| `[[POKE]]` / `[[DICE]]` / `[[RPS]]` | 戳一戳/骰子/猜拳 |
| `[[OOPS]]..[[/OOPS]]` | 发完 1.2s 撤回（说错话） |
| `[[AT]]` / `[[AT:qq]]` | 真 @ 段（单条≤3） |
| `[[VOICE:x]]` / `[[SING]]` | 火山 TTS / Breeze 歌声 |
| `[[AFFINITY:±N]]` | 好感度微调 |

- meme 池自动收集会话图 + vision 写 ≤15 字情绪标签，200/会话淘汰；`[[MEME:情绪]]` 按 tag 命中。
- typing sim + `replyPartDelay`（350ms ±17% 抖动，Asleep ×1.5）——泡间节奏像打字间隙。

## 7. 主动性（proactive）

- 群聊：冷场 45min + 12% + 4h 冷却 + 每天 5 条，`QQ_PROACTIVE_GROUPS` 圈群。
- 私聊：`QQ_PROACTIVE_PRIVATE` 白名单强制 opt-in，空闲门槛 2h。
- 无材料时 chance ×0.35（`HasThoughtMaterial` 念头门）；注入 RecentFacts + 私聊 Impression + Circadian + tone bans。
- 可回 `[[SKIP]]` 放弃——主动说话也要有"想想还是算了"的自由。

## 8. 防 AI 特征（出站剥除）

- `scrubMarkdown`：```、**、>`、`标题/列表` 全部剥成纯文本。
- `stripSpeakerPrefix`：剥 `[Y]`/`【Y】`/人格名前缀。
- `filterRefusal`：provider 拒答模板句 → 静默整泡丢弃。
- `providerErrorFallback`：上游报错 → 「生图被拦了 换个说法我再试试」。
- `expandBareEmotionTags`/`parseFaceMarkers`：`[亲亲]` 类裸标签 → 真 QQ face id 或 emoji。
- `inlineMarkerPattern`：未知 `[[..]]` 一律剥，不泄字面。
- `outboundSecretLeakPattern`：sk-/Bearer/PRIVATE KEY 等出站熔断。
- `stripUnrecognizedMarkers`、敏感文件正则、hexRegex 混淆探测——防套话。

## 9. 人格与人际（persona + binding）

- `personas.json`：`system_prompt` + `routing_scope` + `affinity_prompts` + `voice` + `default_image`（生图定脸三级回退）。
- `data/prompts/base-human.md`：全部人格共享的真人准则（一致性/群边界/不模拟消失/反谄媚/礼貌收尾/记忆自然使用）。
- `prompt_file` 绑定域隔离：星澜业务规则只挂 cinlan 域，zkmall 群看不到。
- `member_groups` 私聊按群归属选人格（fail-closed）。
- `Privileged` 白名单放权（10-26）：allowed_users ∪ BOT_ADMIN_USER_IDS；群主/管理员只作身份标注。
- UserCard：昵称/性别/年龄/签名/好友标记/群 badge(role+title)，7 天 TTL，注入 ≤90 字「对方资料」行。
- peerBotIds：同群别的 bot 只观察不回复，历史标 `[其他机器人]`，防互怼。
- 进退群静默感知：notice → 预拉 UserCard + 写 `[群事件]`，被问"谁刚进群"能答。

## 10. 缺口与建议（按优先级）

| 级别 | 缺口 | 说明 |
|---|---|---|
| 高 | **已读不回/晾人** | 即收即回太机器；可加重度项：mood<0 或 Asleep 时被@延迟 30-90s 再回，已读不回最像人 |
| 高 | **语义重复回复** | filterSelfEcho 只查 verbatim；接 vecstore 语义查重（同义换词也算复读） |
| 高 | **群在热聊时不抢话** | proactive 只看冷场 idle；应加"最近 30s 内他人消息 ≥5 条时不插嘴" |
| 中 | **对人差异化** | 同群熟人和陌生人回复长度/语气无硬差异；affinity<5 时偏短偏客气 |
| 中 | **被冷落感** | 自己的消息没人接话 → mood 应微调 -1~-3；现在只统计收到的 |
| 中 | **对方承诺** | PromiseFacts 只跟踪她的承诺；对方说"明天给你"也应进 fact 并到时追问 |
| 中 | **未完话题** | session 有记忆没有"上次说到一半"跟踪；可加 pendingTopic fact 前缀 |
| 中 | **打错字模拟** | 极低概率（<2%）先发带错字再秒撤/更正——高风险拟人杀器，建议可开关 |
| 低 | **语音情绪一致** | TTS 不随 mood 调 emotion 参数（火山支持度待查） |
| 低 | **群氛围感知** | 群里连续争吵时主动劝架或潜水——需要 group mood 聚合 |
| 低 | **多人格互认** | peerBotIds 只防互怼；同群双 bot 没有"同事感"称谓 |
| 低 | **迷糊渐变** | Asleep 是开关不是斜坡；睡醒后前 10min 加个迷糊尾巴更像人 |
