# cinlan-qq-bot 全量功能清单（2026-11-13）

供逐项核对 / 评估本地方案集成用。按子系统分组，标注所在包与关键开关。
`env` 列只写非默认值的开关名，默认开启的不列。

## 1. 消息管线（internal/bot + internal/pipeline）

| 功能 | 说明 | 位置/开关 |
|---|---|---|
| 消息批处理 | 群聊双窗口 1500ms 合并连发；在途收拢（handler 跑着的同会话新消息折叠进 pending，45s 安全兜底）；尾部悬挂标点/接续词探测再延 2s；私聊 1200ms 窗口 | batch.go；`QQ_PRIVATE_BATCH_WINDOW` |
| 复读接龙 | 30s 窗口 ≥2 个不同人复读同一 ≥5 字文本 → 按心情概率接一句（≥40→45%，0-39→25%，-1~-40→10%，≤-40→0%），每链最多接一次+2min 冷却；命中嫌疑词/链接/卡片一律不接（防转广告） | spam_repeat.go echoChain/tryEchoJoin |
| 防刷屏 | 同人连发 >5 条折叠「中间 N 条已省略」；checkRepeatSpam/checkMentionFatigue 独立防刷 | foldSpam；spam_repeat.go |
| 拟人节奏 | readDelay（按字数模拟阅读）、typingDelay、paceReply、replyPartDelay±17%、sulkDelay（心情差延迟，私聊=0 群聊≤5s） | service.go/config.go；TypingMax/ReadDelayMax |
| 拆泡 | softSplitReply ≥40 字按句末标点断两泡；[[NEXT]] 模型主动拆；enforceShortBubbles 短泡保持 | reply_plan.go；MaxReplyChunks |
| follow-up 豁免 | 机器人刚回过的用户 3min 内续聊免 @；pendingGameMove 对局进行中也豁免；notifyOff 时全部豁免失效 | pendingFollowUp/pendingGameMove；`QQ_FOLLOW_UP`/`QQ_FOLLOW_UP_ANY_USER` |
| 弃权 | 纯 [[PASS]] 不发只记观察；混杂内容剥标记照发 | reply_plan.go |
| 出站清洗 | 链接整句剥除（allow_links=false 的群）；密钥熔断（sk-/Bearer/KEY= 出站拦死）；markdown scrub；行戳剥除；未识别 [[..]] 标记剥除；表情黑名单（微笑:14） | reply_plan.go/outbound_banned.go |

## 8. 记忆体系（internal/chatprefs + vecstore + session）

| 层 | 说明 |
|---|---|
| 会话 | 原始历史 24h；压缩摘要+语义 memory 保留 365 天（SESSION_SEMANTIC_TTL）；handoff 人工接管标记 |
| facts | 每聊 40 槽活跃记忆，溢出进 Archive（2000 槽），再满坍缩成「很久以前」模糊痕迹不硬删 |
| 记忆质量 | memoryWorthy 拒噪音（<4字/filler 黑名单）；去重；Proofs 多证合并；Prev 冲突链记新旧信念张力 |
| 召回 | CJK bigram 词面 + 本地 256 维概念簇 + 远程 embedding 0.7/0.3 混合打分；热度 Weight×；30 天半衰期；冷带「突然想起来」区间 |
| 成员定向 | AddFactForUser/MemberMemory 记到具体人，召回出「阿伟说的」 |
| 承诺跟踪 | 「承诺·」fact → PromiseFacts 注入 prompt+proactive，>24h 附日期 |
| 纠错/语气 | [纠错] 观察；ToneBans≤20 封词，stageAgent+proactive 前置提示 + applyToneGuard 出站兜底 |
| 印象 | impressions 记对每个用户的看法，注入私聊 prompt |
| UserCard | 公开资料卡（昵称/性别/好友/群角色头衔）7 天 TTL，发言者资料注入 prompt |
| 日记 | reflect.journal 每日人格声线日记进 fact 正常召回 |
| 抽取 | extract.go 每轮后 judge 抽记忆（QQ_MEMORY_EXTRACT，60s 节流） |
| 向量缓存 | vec-cache.json 磁盘缓存，热路径零 IO；AddFact/WarmAsync 新记忆即暖 |
