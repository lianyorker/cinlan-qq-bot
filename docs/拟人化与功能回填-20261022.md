## 消息合并

- `QQ_GROUP_BATCH_WINDOW=3s`（默认 900ms 太短，秒级连发合不上）。
- `batch.go` debounce：同用户同群连发在窗口内合并为一条事件（`\n` 拼接），
  定时器随新消息重置；非群消息、不允许的群、`/` 前缀不合并。

## 回复节制（两层）

- **同文刷屏** `internal/bot/spam_repeat.go`：同一用户窗口内重复同文
  ≥`SPAM_REPEAT_COUNT`(3) 触发；`SPAM_REPEAT_MODE` 支持加权随机，
  当前 `ignore:60,hint:25,voice:15`（六成沉默装死）。好感度每个 streak
  只扣一次；hint 提示是"冷淡敷衍"而非骂人；`ignore`/`off` 直接丢。
- **@疲劳（mention fatigue）**：`noteReplySent` 记录群内连续回复同一
  用户的次数；连续 ≥`MENTION_FATIGUE_COUNT`(3) 后，该用户后续消息按
  `MENTION_FATIGUE_IGNORE_PCT`(65) 概率静默丢弃，
  `MENTION_FATIGUE_WINDOW`(10m) 过期清零；仅群聊、换人被回复自动重置。
  对付"换着文案追问同话题"的纠缠。env 均可调，COUNT=0 关闭。
- 私聊不套疲劳（唯一对话方不该被冷落）。

## 上下文断层修复（环境消息进历史）

- 之前 session 只记 `AddExchange`（回复过的对话），没回的群聊消息完全不进
  历史——别人在她答话间隙聊的梗她看不见，是"没上下文感"的主因。
- `internal/session/store.go` 新增 `AddObservation(key, userText)` 记单条
  user 消息；`AddExchange` 在尾条已是同文 user 时只补 assistant（去重）。
- `pipeline.go` `stageSession`（sessionID+promptText 就绪后）对每条到达消息
  调 `AddObservation`——attention 拒掉的闲聊也进历史。core 已同款镜像。

## 安全门禁（SQL 文件泄露修复）

- `FRIEND_FILE_GROUPS=<群ID1>,<群ID2>`（zkmall 两群，见服务器 `.env`）双路门禁：
  1. 好友自动欢迎文件只在发送者是允许群成员时上传
     （onebot `deliverFriendWelcome`）。
  2. `keywordTool.groups`：SQL 关键词的文件发送/引导话术只对允许群或
     其成员出现（pipeline）。
- 泄露原因：`FRIEND_FILE_PATH` 全局生效 + 关键词正则全局触发。

## 跨域隔离审计（2026-10-22 夜）

逐面核对"不同群的文档/文件交叉发"风险：

- **session**：按 `platform:self:X:group|private:chatID` 分 key，群聊观察只进本群历史 ✓
- **chatprefs/remember**：key=`chatType:chatID`，记住的内容不跨群 ✓
- **proactive**：取本群 session 历史做 opener，无跨群上下文 ✓
- **knowledge**：按绑定 `knowledge_bases` 过滤，cinlan/zkmall 隔离刻意保持 ✓
- **keyword 文件**：`kt.groups` 门禁 + 私聊群成员校验 ✓
- **filedelivery catalog**：security boundary 圈定 ✓

发现并已修的三个洞（`internal/tool/channelaction.go`，core 已镜像）：

1. **群主用不了**：`Actor.Role=SenderRole` 直通 QQ 角色，但只认 `admin`——
   `owner` 被挡。已修：`admin || owner` 同权。
2. **跨聊发送**：群管理员可对**任意群** `send_group_msg`/`upload_group_file`
   ——跨域文件/消息泄露口。已修 `crossChatTargetViolation`：`group_id` 必须
   等于当前聊天；`send_private*`/`upload_private*` 的 `user_id` 必须等于
   当前聊天；私聊语境带 `group_id` 直接拒。（`set_group_ban` 里的 `user_id`
   是被操作对象不是目的地，不动。）
3. **文件路径无约束**：`upload_group_file` 可传服务器任意路径（知识库、
   .env）进群。已修 `filePathViolation`：本地路径必须在 `BOT_ALLOWED_ROOT`
   内，http/base64 放行；`ChannelActionTool(platforms, cfg.BotAllowedRoot)`
   变参兼容旧签名。

遗留提示：`safeChannelActions` 只读白名单 + `send_like` 对全员开放；
写/管动作要求 admin/owner（= QQ 群管及以上）；跨域广播能力从工具层
已封死，需要时单独做 admin 工具。persona pack 的 `KnowledgeDir` 字段
已解析但未接 knowledgeStore——启用 packs 前按需接线。
