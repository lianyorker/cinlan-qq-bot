# 公开部署指南

本文档说明如何在不把账号数据、私有业务规则或凭据带进 Git 的前提下，完成一次干净的部署。

## 准备本地配置

复制模板并只编辑本地副本：

```powershell
Copy-Item .env.example .env
notepad .env
```

至少设置你自己的群号和 Agent endpoint：

```dotenv
QQ_PLATFORM=native
QQ_GROUP_ALLOWLIST=123456789
QQ_PRIVATE_ALLOWLIST=987654321
AGENT_API_MODE=openai
AGENT_API_URL=https://api.example.com/v1/chat/completions
AGENT_MODEL=your-model
```

`AGENT_API_KEY`、`SESSION_ENCRYPTION_KEY`、`ADMIN_API_TOKEN`、OneBot token、cookie 和 provider 凭据只保存在进程或用户环境变量中。不要把它们的值写进 `.env`、JSON、Markdown、日志或截图。

## 配置隔离的 Binding

创建或编辑本地 `data/chat-bindings.json`。整个 `data/` 目录都被 Git 忽略，因此可以存放部署专属的 Persona、知识库、Skills、MCP 引用、会话数据库和生成的媒体文件。

```json
{
  "bindings": [
    {
      "name": "support-group",
      "platform": "*",
      "self_id": "1000000000",
      "chat_type": "group",
      "chat_ids": ["123456789"],
      "persona": "support",
      "tools": ["capture_webpage"],
      "knowledge_bases": ["support"],
      "require_mention": true,
      "learning_enabled": true
    }
  ]
}
```

聊天只能看到 Binding 声明的资源。即使复用同一个 Persona，群聊历史、私聊历史、摘要和学习记忆也保持相互隔离。

## 添加本地业务行为

私有 Persona 提示词放在 `data/personas.json`，私有知识库放在 `data/knowledge/`，私有文件放在 `files/`。不要把这些文件加入公开提交。被跟踪的 `examples/` 文件只包含占位内容。

网页截图使用精确的 HTTPS host 白名单：

```dotenv
WEB_SCREENSHOT_ENABLED=true
WEB_SCREENSHOT_BROWSER_PATH=C:\Program Files\Google\Chrome\Application\chrome.exe
WEB_SCREENSHOT_ALLOWED_HOSTS=example.com
```

浏览器不会复用桌面登录会话。不要在公开示例中加入内部域名或需要鉴权的 URL。

## 启动与验证

```powershell
.\scripts\build.ps1
cmd.exe /k powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1
```

登录后验证本地 runtime：

```powershell
Invoke-RestMethod http://127.0.0.1:18080/healthz
Invoke-RestMethod http://127.0.0.1:18080/readyz
```

前台进程用 `Ctrl+C` 停止。

## 发布前检查

提交或推送前运行：

```powershell
.\scripts\check-public-release.ps1
```

检查会扫描被跟踪文件和暂存新增内容中的私有路径、凭据模式、本地 QQ 路径，以及被忽略的 `.release-private-patterns.txt` 里的可选模式。部署包含业务专属标识时，把私有词条或 URL 每行一条加进该本地文件。该文件本身被忽略，绝不能暂存。

## 构建公开包

只在清理过的公开分支上运行打包命令：

```powershell
.\scripts\package-release.ps1 -Version 0.2.0
```

脚本会在 `dist/` 下生成 Windows x64、macOS Intel 和 macOS Apple Silicon 压缩包，以及 SHA-256 校验文件。Windows 包包含 native QQNT loader 和 hook；macOS 包只包含 Go runtime，支持 `QQ_PLATFORM=onebot`，native QQNT 注入仅限 Windows。

打包过程会为 release 构建清空 `GOFLAGS`，因此被忽略的本地 build-tag 扩展不会进入公开包。不要上传 `dev`、`.env`、`data/`、`files/`、`exports/`、本地扩展文件或 release 暂存目录。
